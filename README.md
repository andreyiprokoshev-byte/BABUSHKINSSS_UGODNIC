# Пирожковый Двор 3D (Windows .exe + Web)

3D-аркада с открытым миром на **Tauri v2 + React + TypeScript + Three.js**, готовая к сборке в нативное приложение для **Windows (`.exe`)** и совместной разработке на GitHub.

## Что есть в игре
- **Открытый 3D-двор**: ходьба от первого лица (`WASD`), бросок пирожков (`Q` / `ПКМ`), взаимодействие (`E`), бешенный питбайкер с «Балтикой 0».
- **Живые мемные бабушки**: артикулированные 3D-модели, разные мем-лица, русская озвучка фраз и мини-игра угощения пирожками.
- **Бабушко-боулинг**: сбивай банки с лавочки на алее.
- **Угон «Жигулей» и покатушки**: угоняй авто на `E`, сажай бабушку рядом, гуди на `G`, выходи на `F`.
- **Контора Петровича и закладчики**: отбирай свёртки пирожками и развози заказы по точкам за кэш (`₽`).
- **Магазин 24/7 (`B`)**: покупки за **Кирики**, **Газяву** и **Рубли** — от семечек и пирожкомёта до короны двора.
- **Саундтрек**: встроенный плеер (`DJ Бутылыч — ГАЗЯВА`).

## Быстрый старт на Windows

### Вариант 1: Скачать готовый `.exe` с GitHub Actions (без установки Rust)
1. Откройте вкладку **Actions** в репозитории GitHub.
2. Выберите последний зелёный запуск workflow **Desktop EXE Build**.
3. Скачайте артефакт **`windows-exe-installer`** — внутри лежит установщик `*-setup.exe` и готовый `pirozhkovy-dvor.exe`.

### Вариант 2: Запустить и собрать `.exe` локально
Нужны **Node.js 24 и Bun 1.4.5**, **Rust (rustup + MSVC Build Tools)** и **WebView2** (в Windows 10/11 уже есть).

```bash
# 1. Установить зависимости
bun install --frozen-lockfile

# 2. Быстрая разработка в браузере (горячая перезагрузка, удобно верстать)
npm run dev

# 3. Запустить как нативное окно Windows (.exe в dev-режиме)
npm run desktop

# 4. Собрать готовый Windows .exe и установщик NSIS
npm run desktop:build
```

Готовый файл появится в:
- `src-tauri/target/release/pirozhkovy-dvor.exe`
- `src-tauri/target/release/bundle/nsis/Пирожковый Двор 3D_0.1.0_x64-setup.exe`

Подробная памятка для совместной работы и внесения изменений — в [CONTRIBUTING.md](./CONTRIBUTING.md).
